# 已知问题

## 手机长期显示旧离线缓存

- 来源：使用者实际反馈。
- 表现：显示离线缓存提示，内容停留在较早版本。
- 原因：尚未确认，需要检查电脑服务、私人连接、认证和缓存恢复流程。
- 状态：待排查；不能作为已修复案例宣传。
- 验收目标：电脑服务与连接可用时能更新；暂时断网后恢复可重新同步；准确显示最后同步时间；离线数据不冒充最新数据。

## 电脑关闭或休眠时无法持续采集

当前采集依赖电脑运行。手机上的离线界面不等于手机具有独立采集能力。独立手机采集和云端方案尚未实施。

## 模型提取与合并仍可能有误

保留原文依据、人工纠错与撤销。没有有效原文依据的时间不应被当成确定日程。

公开副本不提供签名 APK。私人新版的安装完成与头像选择需要实际手机确认；浏览器测试不能替代 Android 实测。
