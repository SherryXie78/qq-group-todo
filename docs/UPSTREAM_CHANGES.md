# 相比上游做了什么

对比依据：本地保存的 `qq-live-digest` 快照 `a36b538e5a5760b6381beec3196eebc59a7e4d4e` 与当前核心 Python 文件的字节比较。统计限于 `qq_live_digest/*.py`，不含前端、测试和部署脚本，也不是代码原创比例。

上游已经提供消息接收、规则过滤、摘要、存储、去重、推送及基础移动待办等能力。上述基础能力属于上游贡献。

## 新增核心模块（14）

| 模块 | 本项目增加的工作 |
| --- | --- |
| `groups.py` | 工作台管理监控群列表 |
| `history_review.py` | 选定群和时间段的历史审查编排 |
| `manual_tasks.py` | 手工补录任务与重复提交防护 |
| `task_review.py` | 自由文本纠错、保留修正与审查流程 |
| `task_plan.py` | 时间 / 地点 / 行动呈现与阶段任务 |
| `task_intelligence.py` | 新通知与已有任务的候选匹配和拆分辅助 |
| `temporal.py` | 北京时间、时间范围与倒计时 |
| `daily_advice.py` | 按待办生成建议，缓存及调用预算限制 |
| `calendar_view.py` | 日历数据和本地课程管理 |
| `mobile_access.py` | 私人连接检查与手机访问配对 |
| `android_install.py` | 已授权安装包的校验、分段下载与过期凭据 |
| `qq_session.py` | 采集状态与经确认的电脑端登录操作入口 |
| `qq_window.py` | 恢复已有 QQ 窗口，避免重复打开登录 |
| `pet.py` | 事务化积分、头像和互动账本 |

## 修改核心模块（7）

`ics.py`、`providers.py`、`service.py`、`store.py`、`summarizer.py`、`timeutil.py`、`webapp.py`。

对应工作包括 DeepSeek 提取规则、多事项与多阶段保存、审计与撤销、北京时间转换、阶段日历导出、前端视图与手机缓存流程。保留不变的 28 个核心模块继续按原许可证注明来源。

## 前端与集成

增加群管理、历史审查、文本纠错、日历、登录状态、宠物视图和安装下载进度等界面；增加本地依赖资源，避免使用时依赖公共 CDN。

私人安装环境曾使用 NapCat 接收方案，后调整为与普通电脑 QQ 共存的采集接入。Renecon 为早期调研对象，不是当前工作台引擎。共存采集器受其自身许可约束，公开仓库保留架构说明，不发布其修改版运行件。
