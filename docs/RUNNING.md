# 运行与验证

仓库根目录运行 `python run_demo.py`。默认端口 8876，仅绑定回环地址；首次创建虚构任务，之后保留演示库中的修改。设置 `--port` 可选择其他端口，`--no-browser` 可不打开浏览器。

演示不读取原电脑的配置或环境变量中的模型密钥，不连接任何 QQ 账号，不发送消息，也不调用付费模型。运行时随机生成本机访问 token，保存在被忽略的演示数据中，不将实际访问链接写入说明或日志。

工作台的在线采集、历史聊天读取、实际 DeepSeek 调用、移动设备配对与 Android 安装需要单独部署，不因启动演示而启用。未配置的功能会提示不可用，不能把演示效果当成完成真实接入。

在 `app` 目录运行检查：

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests
```

测试使用临时数据和伪造模型响应；涉及本机 HTTP 的检查需要允许回环网络。测试不会作为真人 QQ 账号发送消息。
