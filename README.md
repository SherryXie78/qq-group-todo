# Q群消息代办

把群聊里的长通知，整理成突出时间、地点和行动要求的待办。

这是一个从校园真实需求出发、持续试用迭代的个人项目。面对多群聊和分散通知，使用者希望减少重复阅读，并能够核对原文、纠正提取结果、分阶段完成任务。

## 来源与项目贡献

消息处理引擎基于 [wc985732-lang/qq-live-digest](https://github.com/wc985732-lang/qq-live-digest)，保留原 MIT 许可证与作者声明。对比的本地上游快照为 `a36b538e5a5760b6381beec3196eebc59a7e4d4e`。这不是从零独立手写全部代码的项目。

在该快照的 Python 核心模块基础上，新增 14 个模块、修改 7 个模块，另有 28 个模块保持一致。功能与边界详见 [改动说明](docs/UPSTREAM_CHANGES.md)。项目发起者负责需求、优先级、使用反馈和验收，使用 AI 编程工具辅助开发。

## 当前工作台能力

- 选定群消息的接收、降噪、重要事项提取与原文核对。
- 时间、地点、行动要求分开展示；北京时间与截止倒计时。
- 自由文本纠错，支持保留并修正任务及查看变更记录。
- 单条通知中的多个事项、重复通知与多阶段截止时间处理。
- 按群与时间范围发起历史审查，以及手工补录任务。
- 本地日历、课程编辑和 iCalendar 导出。
- 电脑与手机工作台、离线缓存和私人连接状态提示。
- 完成任务积分、自定义形象及趣味互动。

AI 结果需要结合原文核对；错误提取、误合并与移动连接可靠性仍是持续改进方向。

## 公开版范围

本仓库发布脱敏的工作台框架、核心逻辑、测试与 Android 容器源码文件。包含可独立运行的本地演示入口；演示不会连接 QQ、调用 AI 或向任何群发送消息。

真实聊天、真实群号、账号、凭据、数据库、私人访问链接、已登录的采集器、构建缓存和 APK 签名材料均不发布。

采集层是独立集成点，**本仓库不附带 SnowLuma 修改版、其原生组件或登录配置**。SnowLuma 本地副本的许可证限制修改版公开发布；相关运行件不纳入本项目的 MIT 许可。Android 文件也不构成完整、可直接构建的独立 APK 工程。公开仓库与私人安装环境的差异见 [集成边界](docs/INTEGRATIONS.md)。

## 快速体验

需要 Python 3.12 或更新版本。以下命令在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_demo.py
```

浏览器会打开本机演示工作台。演示仅包含程序创建的虚构任务，界面变化保存在被忽略的 `demo-data/` 中。按 `Ctrl+C` 停止。更多说明见 [运行说明](docs/RUNNING.md)。
